# IPUMS source data — not redistributed

The files in this directory (`H_*.csv`, `nhgis0001_*`) are extracts from
IPUMS USA and IPUMS NHGIS. IPUMS licensing prohibits redistributing these
extracts outside the research team that obtained them, so they are kept
local-only: excluded from the public Internet Archive corpus and not
committed to a public GitHub remote.

To reproduce these extracts, request them directly from IPUMS under your
own account:

- https://usa.ipums.org/
- https://www.nhgis.org/

If citing derived statistics or datasets built from these files in public
research outputs, cite IPUMS per their required citation, not the raw
extract files themselves.
