    How to add photos

    Everything lives in the shared Google Drive folder. Whatever you put there shows up in the album, usually within a minute.

    Folders are chapters

    Make a folder for each part of the story. Put a number at the front to set the order — the number won't show.

    01 Early years
    02 The farm
    03 Keepsakes

    Name each photo with its year

    Start the name with the year, then a few words.

    1948 - Wedding day.jpg
    about 1955 - Picnic at the lake.jpg
    1960s - The old Buick.jpg

    Not sure of the year? Write "about" in front, or use the decade like "1960s".

    Write the story in the Description box

    In Google Drive, open a photo's details (the i button) and type in Description. That becomes the caption. To say where it was taken, add a line like Place: Joliet.

    Keepsakes and letters

    For a scanned keepsake or letter, add #keepsake or #letter anywhere in the description. A folder with "Keepsakes" in its name does this for everything inside.
